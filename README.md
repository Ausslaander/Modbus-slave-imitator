# Имитатор ВЧ-генератора GLine

## Состав

- `gline_emulator.py` — последовательный Modbus RTU slave, карта регистров 0...40.
- `gline_parameters.py` — отдельные функции законов изменения для всех доступных измеряемых величин.
- `requirements.txt` — зависимость `pyserial`.

## Запуск

```bash
python -m pip install -r requirements.txt
python gline_emulator.py
```

По умолчанию используются настройки исходного проекта: `COM10`, `9600` бод, `8N1`, адрес ведомого `2`.

## Настройка законов измеряемых параметров

Откройте `gline_parameters.py`. Каждая измеряемая величина имеет собственную функцию с аргументом `t` — временем в секундах от запуска имитатора.

Постоянное значение:

```python
def incident_power_average(t: float) -> float:
    return constant(600.0)
```

Синусоидальный закон:

```python
def incident_power_average(t: float) -> float:
    return sinusoid(t, mean=600.0, amplitude=20.0, period=30.0)
```

Здесь `mean` — среднее значение, `amplitude` — амплитуда, `period` — период в секундах, `phase` — начальная фаза в радианах. По умолчанию в файле уже заданы демонстрационные синусоидальные зависимости. Для каждого параметра закон можно менять независимо.

## Поддерживаемые Modbus-функции

- `0x03 Read Holding Registers`: чтение регистров 0...40; можно запросить все 41 регистр одним запросом.
- `0x11 Read Slave ID`: идентификационная строка модели и индикатор включения ВЧ.

Имитатор работает как ведомое устройство. Данные с него снимает внешняя программа-клиент (Modbus master), например Logger. Для соединения через виртуальную пару COM-портов клиент должен открыть второй конец пары, а имитатор — `COM10`.

## Замечания по карте регистров

Карта построена по разделу 11 руководства GLine, редакция 2026-02. Регистры 25...32 содержат 16-битные измеренные значения. Регистры 33...40 содержат по два параметра в одном регистре: старший и младший байты. Значения этих байтов округляются до целых и ограничиваются диапазоном 0...255.

В описании руководства не приведены коэффициенты масштабирования для байтов телеметрии модулей. Поэтому имитатор передаёт численные значения напрямую, как целые байты; при подключении к реальному генератору масштаб необходимо сверить с документацией производителя/показаниями панели.
